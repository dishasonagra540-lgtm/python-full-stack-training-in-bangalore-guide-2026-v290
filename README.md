Here’s a simple example of a Flask route that returns a JSON response:

```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route('/api/data', methods=['GET'])
def get_data():
    return jsonify({"message": "Hello, World!"})

    app.run(debug=True)
```
